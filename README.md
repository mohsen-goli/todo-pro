# Todo Pro 🚀

A modern and responsive Todo application built with HTML, CSS, and Vanilla JavaScript.

## ✨ Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Task priority levels: High, Medium, Low
- Filter tasks by status
- Search tasks
- Sort tasks by priority
- Sort tasks by newest and oldest
- Save tasks with LocalStorage
- Dark mode
- Clear all tasks
- Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage
- Git & GitHub

## 📚 JavaScript Concepts Practiced

This project was built to practice real-world JavaScript fundamentals, including:

- DOM Manipulation
- Event Listeners
- Arrays and Objects
- Array Methods
- `filter()`
- `sort()`
- Conditional Logic
- Functions
- Object Properties
- LocalStorage
- Dynamic DOM Rendering
- Form Handling
- Search and Filtering

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/mohsen-goli/todo-pro.git
```

Open the project folder and run `index.html` with Live Server.

## 🎯 Purpose

Todo Pro is a portfolio project created to practice JavaScript fundamentals through a practical application.

The goal was to build a useful application while learning how JavaScript interacts with the DOM, manages data, handles user interactions, and stores information locally.
